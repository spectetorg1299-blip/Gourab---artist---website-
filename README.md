# GOURAB — Vercel Artist Website

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Deploy to Vercel
1. Put this folder in a GitHub repository, or upload it to Vercel.
2. Vercel detects Next.js automatically.
3. Build command: `next build`
4. Output: automatic.

## Customize
Edit `app/page.tsx` for artist name, songs, lyrics, links and sections.
Edit `app/globals.css` for the visual theme.
Replace the placeholder portrait/video backgrounds with your own images or video assets in `public/`.
